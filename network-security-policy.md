# Basic Network Security Policy

## 1. Purpose
This policy defines the security requirements for protecting the organization's network infrastructure from unauthorized access and threats.

## 2. Scope
This policy applies to all employees, devices, and network resources including routers, switches, firewalls, and servers.

## 3. Network Security Controls

### 3.1 Access Controls
- All network access must be authenticated via username and strong password.
- Role-Based Access Control (RBAC) must be enforced.
- Default credentials on network devices must be changed immediately.
- Remote access must use VPN with multi-factor authentication.

### 3.2 Firewall and Segmentation
- A perimeter firewall must filter all inbound and outbound traffic.
- Internal network must be segmented into VLANs (Admin, Staff, Guest).
- Unused ports on switches must be disabled.

### 3.3 Password Policy
- Minimum 8 characters, with uppercase, lowercase, number, and symbol.
- Passwords must be changed every 90 days.
- No password sharing.

### 3.4 Monitoring and Updates
- Firewall logs and DHCP logs must be reviewed weekly.
- All firmware and antivirus definitions must be updated monthly.

## 4. Enforcement
Any violation of this policy may result in disciplinary action and removal of network privileges.

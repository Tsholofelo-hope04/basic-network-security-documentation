# Network Incident Response Guidelines

## Immediate Steps for Suspected Breaches

### 1. Identify & Isolate
- Disconnect any compromised host or rogue device from the network immediately.
- Identify the type of incident (malware, phishing, unauthorized access).
- Notify the IT security team.

### 2. Evidence Preservation
- Export firewall logs, DHCP logs, and SIEM alerts for the time of incident.
- Take screenshots and backup affected system logs.
- Do NOT delete or format any affected device until investigation is complete.

### 3. Containment and Eradication
- Block malicious IP addresses on the firewall.
- Disable compromised user accounts.
- Run full antivirus/malware scan and remove threats.

### 4. Recovery
- Restore clean backups if needed.
- Reset passwords for affected accounts.
- Reconnect systems only after verification.

### 5. Monitoring and Lessons Learned
- Monitor network for 72 hours after recovery for recurring activity.
- Document the incident: date, cause, impact, and actions taken.
- Update security policies to prevent future incidents.
